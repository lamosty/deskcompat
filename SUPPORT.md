# Support

DeskCompat is pre-alpha. It is not yet appropriate for production workstations.

- Use [GitHub Discussions](https://github.com/lamosty/deskcompat/discussions) for
  questions and design discussion.
- Use [GitHub Issues](https://github.com/lamosty/deskcompat/issues) for reproducible
  bugs and scoped feature proposals.
- Use a private advisory for security or lockout risks; see [SECURITY.md](SECURITY.md).

Only platforms listed in [docs/supported-platforms.md](docs/supported-platforms.md)
are candidates for support. A detected-but-unsupported platform is not permission
for the tool to guess or mutate it.
